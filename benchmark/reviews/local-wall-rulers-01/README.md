Use exactly the same pixels (up to 384 per tile) in all arms. The finite options are the ordinary integer level plus offsets −3, −1, +1 and +3. At each level, test the canonical unit grid, two positive quarter-block shifts (U or V), and centered half/double-pitch alternatives. Each fit can choose a legal side sprite and orientation, using intensity correlation to tolerate constant gain and offset. These choices bound both phase and level coverage.

* **Rectified crop** bins the native observations into oriented 16×16 texels and compares their averages against the sprite. **Native** projects four atlas subsamples beneath each native pixel. This is a comparison of two sampling domains on identical observations. The crop arm is a binned rectification, with no additional photographic interpolation or separately fitted blur.
* **Single** fits one tile. **Shared** fits the same sprite and one grid on tiles one and two. Verify the winning grid/sprite on the entire third tile. Fit correlation must reach .62 and independent verification .52. **Native mixed** allows separate sprites on the first two tiles with a shared grid, chooses a third sprite on the third tile’s center stripe, then scores its untouched seam-side stripes. Two accepted mixed fits switched sprites between the two fitting tiles.
* Only accepted integer, zero-phase, unit-pitch proposals can become strict chart carriers. The standard placement pipeline applies its full-support cell test, opening vetoes, later placement edits and ordinary material export. A local match is applied to its source wall mask, which can include multiple depths. No unseen cell or surface is generated by the ruler. A carrier on the existing ranked level can still affect previously unresolved strict grid cells.

Thin raster edges, occlusion and wall boundaries can leave a guessed line unmatched. Opening edges and material-transition edges were not separately graded. ## Reproduce

Use the workspace Python containing OpenCV, NumPy and Pillow, the frozen control worktree, and the prepared Java 26.3 atlas. From this checkout:

```powershell
python -m benchmark.local_wall_rulers --split development
python -m benchmark.local_wall_rulers --split transfer
python -m benchmark.local_wall_ruler_audit
python -m benchmark.local_wall_ruler_exports --workers 4
python -m benchmark.local_wall_ruler_cottage
python -m benchmark.local_wall_ruler_summary
```
