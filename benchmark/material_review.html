Visible block materials and placement

Placement F1 measures whether a visible block is in the right position relative to the build. Material accuracy measures the exact Minecraft ID among those correctly placed blocks. Overall F1 requires both the position and ID to match. A wrong ID counts as one missing block and one extra block.
