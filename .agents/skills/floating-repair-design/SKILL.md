Work from a specific diagnosis, a matched Perfect result where available, prior decisions and an actionable visual. State two plausible explanations in ordinary language. Ask which observation would tell them apart. Use pattern recognition, perspective, texture, line continuity or an OCR-style repetition model when it offers an independent cue; describe the cue and how it can be wrong. The cheapest deterministic replay that discriminates between explanations comes first.

Read [Choosing and evaluating Floating experiments](../../../benchmark/FLOATING_MODEL_EVALUATION.md). Check whether better options need to be generated, existing options need to be selected, or downstream assembly needs to preserve a measured gain. Hunt for runnable pretrained cues when they could improve a high-headroom handoff, then decide what earns a development replay or training run.

Astra high designs the experiment. Brief Astra medium with the hypotheses, incumbent, option set, one changed handoff and frozen acceptance check. Sol high scores decoded exports. Build families used for diagnosis remain development/regression cases. For a learned chooser, measure option headroom, collect training labels from visible truth on development families, fit an image-only selector, include abstain/keep-incumbent, and compare against a simple rule on unseen families. Use the same single whole-build translation for material and placement.

Report correct gained/lost, extras added/removed, exact material and camera/orientation failures. For a trade-off, show which weights change the result and which families gain or regress. Connect promotion to measured source-only transfer. Record the decision and outcome against the original question. Return one source-image explanation Jeremy can understand.
