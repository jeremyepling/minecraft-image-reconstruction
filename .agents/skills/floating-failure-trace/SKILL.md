description: Trace visible-block reconstruction failures from decoded placements through surfaces, depth, rulers and selection on the Floating branch.
---

Use the report, case receipts and per-surface evidence from the same comparison. Begin with the observed lost or extra coordinates and trace back through the chosen component, attempted grids, depth partitions and source mask. Record the earliest handoff supported by evidence and the last known-good one. Separate an available grid that was discarded from a grid that was never generated. A selected chart alone does not establish ownership of every exported block.

Compare native source-image overlays for coverage, alignment and full-face spacing independently. Inspect both axes when a tiny ruler creates many extras. Check parallel walls for separate depth and corner joins for overwritten local rulers. Compare a dropped yet well-counted surface against the kept group and preserve visible openings in the replay. Group repeated failures across buildings and use direct case/surface links.

Return the measured effect, alternative cause, and smallest discriminating test. If the necessary evidence was never recorded, request that instrumentation in the machine queue. Escalate to Jeremy only if two visible interpretations remain plausible and the answer changes a named action.
